# WikiSkill for Grok Bot / WikiSkill pour Grok Bot
<img width="1984" height="992" alt="image" src="https://github.com/user-attachments/assets/8a98a81f-a281-4cc5-ae5a-4f9cde1f1d6d" />


Native WikiSkill pack for [Grok Bot](https://x.ai/bot). Bilingual repository.

- **English (US):** [README.us.md](README.us.md) · [X article](docs/article-x/us.md)
- **Français:** [README.fr.md](README.fr.md) · [Article X](docs/article-x/fr.md)

Paper: Tang et al., *WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution*, [arXiv:2608.27454](https://arxiv.org/abs/2608.27454).

Paste-ready prompts and `SKILL.md` files stay in **English** — that is Grok Bot’s product language.

```
prompts/                 English, paste into Grok Bot
skills/*/SKILL.md        English, product format
docs/article-x/fr.md     French X Article
docs/article-x/us.md     US English X Article
TEAM.md                  French roster + team rule
TEAM.us.md               US English roster + team rule
INSTALL.fr.md / INSTALL.us.md
LAYOUT.fr.md / LAYOUT.us.md
```
